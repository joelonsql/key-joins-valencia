What is a <key join specification>?

FOR KEY makes the intent to write a key join explicit and requires the DBMS to verify it before execution.

The column lists follow operand order. The arrow points from referencing to referenced.

  • The DBMS proves sufficient conditions from the schema and query structure.
  • If it cannot prove them, it rejects the statement.
  • If accepted, FOR KEY is transformed into an ON condition that compares the corresponding columns for equality.
